Lab 3 · Build a Java Project

Lab 3 – Build a Java Project

In this lab, Jenkins builds a real Java project stored on GitHub: it compiles the code, runs the tests, packages a .jar file and waits for your approval before deploying it. On the way you use six plugins.

Objectives

  • Run a pipeline whose Jenkinsfile is stored in a public GitHub repository (no token needed).
  • Read the results produced by plugins: JUnit (tests), Artifacts (files to download), Timestamper, Workspace Cleanup.
  • Use build parameters and see an unstable (yellow) build.
  • Write your own pipeline with a manual approval before deployment.
  • Install a new plugin: AnsiColor.

Session plan (1h30)

  1. Meet the Java project (5 min)
  2. The Jenkinsfile line by line (15 min)
  3. Run it from GitHub (10 min)
  4. Plugins at work (10 min)
  5. Break the tests (10 min)
  6. Your own Java pipeline (25 min)
  7. Install a plugin: AnsiColor (10 min)
  8. Checklist and hand-in (5 min)

Before you start

  • Jenkins is running and you can log in at http://localhost:8080.
  • Lab 2 is done: you know New Item, Configure, Build Now and Console Output.
  • The Git plugin is installed: when you create a Pipeline job, the SCM list offers Git.
Jenkins in Docker or on Windows? Every script of this lab exists in two versions. Jenkins in Docker (Lab 1 path) uses sh. Jenkins installed directly on Windows uses bat, and needs Git for Windows and a JDK (not only a JRE) installed on the computer. Always take the version that matches your Jenkins.
