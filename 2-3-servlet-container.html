2.3 Servlet Container

Because Jenkins is distributed as a standard WAR file, you can deploy it on a Java application server (servlet container) such as Tomcat.

Steps

  1. Copy jenkins.war into the webapps folder of the application server.
  2. Restart the application server.

With Tomcat, Jenkins is then available at http://<server>:8080/jenkins.

Pros and cons

  • Pro: system administrators manage one application server instead of several.
  • Con: more complex to set up and maintain, and you lose some convenient features, such as upgrading or restarting Jenkins from its own interface.

Not every server version works: check the servlet container support policy.
