Lab 3 · Build a Java Project

5. Break the Tests

What does Jenkins do when a test fails? Use the parameter to put a bug in the calculator, without changing any code.

Step 1: Build with the bug

  1. On the job page, click Build with Parameters.
  2. Tick SIMULATE_BUG, then click Build.

Step 2: Read the result

  • The build is yellow (or orange): UNSTABLE. The code compiled, but tests failed. Red (FAILURE) is kept for builds that cannot run at all.
  • In Console Output: FAIL add_2_and_3: expected 5 but was 6.
  • On the build page, Tests shows 2 failures. Click a failed test to read the message.
  • On the job page, the Test Result Trend chart shows the failures in red.

Step 3: Fix it

Click Build with Parameters, leave SIMULATE_BUG unticked, click Build. The build is green again, and the chart shows the fix.

Question for the hand-in: look at the Package stage of the yellow build. Did Jenkins still create calculator.jar? In a real team, would you deploy it? (Answer in part 6: this is why we add a manual approval before deploying.)
