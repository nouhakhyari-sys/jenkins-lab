Lab 3 · Build a Java Project

7. Install a Plugin: AnsiColor

The logs are black and white. The AnsiColor plugin shows colours in the Console Output. You install it like the Stage View plugin in Lab 2.

Step 1: Install the plugin

  1. Manage Jenkins (gear icon) › Plugins › Available plugins.
  2. Search AnsiColor, tick AnsiColor, click Install.
  3. Wait for Success, then go back to the top page.

Step 2: Use it in your pipeline

  1. Open my-java-pipeline › Configure.
  2. Replace the options block with:
options with colours
    options {
        timestamps()
        ansiColor('xterm')
    }
  1. In the Test stage, after the dir(…) { … } block, add two coloured messages:
Green and red messages (same in Docker and Windows)
echo "\u001B[32mAll tests passed!\u001B[0m"
echo "\u001B[31mThis line is red\u001B[0m"
  1. Save, build, open Console Output: one line is green, one is red.

\u001B[32m is an ANSI code that means "write in green"; \u001B[0m means "back to normal". Build tools such as Maven and npm use the same codes.

Error "Invalid option type ansiColor"? The plugin is not installed, or Jenkins needs a restart: run docker restart jenkins-local (Docker) or restart the Jenkins service (Windows), then build again.
