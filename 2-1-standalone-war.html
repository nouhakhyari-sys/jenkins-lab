2.1 Standalone WAR

With this method, Jenkins runs as a standalone application in its own process, using its embedded web server (Jetty). You download it as a Java WAR (Web Application Archive) file, jenkins.war, which runs on any operating system that has Java.

Steps

  1. Download the latest LTS jenkins.war from the Jenkins download page.
  2. Open a terminal in the download folder and run:
Start Jenkins from the WAR file
java -jar jenkins.war

By default, Jenkins uses port 8080: open http://localhost:8080 in your browser. The initial admin password is printed in the terminal, and stored in ~/.jenkins/secrets/initialAdminPassword.

Change the port and other options

Pass Jenkins options after the file name. For example, to use port 9090:

Run Jenkins on another port
java -jar jenkins.war --httpPort=9090

The general form is java [JAVA_OPTS] -jar jenkins.war [JENKINS_OPTS]: Java system properties go before -jar, Jenkins options go after the file name. Here is an example with several options:

Example with several startup options
java -Dhudson.footerURL=http://example.org -jar jenkins.war \
  --httpPort=8083 --prefix=/ci --httpListenAddress=127.0.0.1

In this example:

  • -Dhudson.footerURL=http://example.org is a Java system property: it changes the link in the Jenkins footer.
  • --httpPort=8083 uses port 8083 instead of the default 8080.
  • --prefix=/ci adds /ci to the Jenkins URL.
  • --httpListenAddress=127.0.0.1 makes Jenkins reachable only from this machine.

Result: Jenkins is reachable only at http://127.0.0.1:8083/ci.

Run java -jar jenkins.war --help to list all options, and see Jenkins features controlled with system properties.
