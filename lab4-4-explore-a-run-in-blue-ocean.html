Lab 4 · Freestyle Projects and Blue Ocean

4. Explore a Run in Blue Ocean

Open your Lab 3 pipeline in Blue Ocean and run it with the bug. You will see the same information as in the classic interface, organised differently.

Step 1: Run the pipeline with the bug

  1. In Blue Ocean, click my-java-pipeline. You arrive on the Activity tab: one line per run.
  2. Click Run (top). Blue Ocean asks for the parameters: tick SIMULATE_BUG and click Run.
  3. Click the new run. The stages are drawn as connected circles: Checkout → Build → Test → Package → Deploy. They fill in while the run progresses.
  4. The run stops on Deploy: Blue Ocean shows the question of your input step, with the buttons Deploy and Abort. Click Abort: you would not deploy a build with a failed test.

Step 2: Read the run

  • Click a stage circle: below the graph, you see only the steps of that stage. Click a step to open its log.
  • Tests tab (top): the failed tests come first, with their message.
  • Artifacts tab: the files kept by archiveArtifacts, ready to download.
  • Changes tab: the Git commits that arrived since the previous run. Here it says There are no changes for this run: ticking SIMULATE_BUG is a parameter, not a change of code, and nobody pushed to the repository. You will see real changes in part 6.

Run the pipeline once more without the bug and click Deploy, so you also have a green run.
