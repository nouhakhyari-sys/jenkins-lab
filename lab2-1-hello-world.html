Lab 2 · Your First Pipeline

1. Hello World Pipeline

We write a "Hello World" pipeline using the declarative pipeline syntax.

Step 1: Create the job

  1. On the Jenkins dashboard, click New Item.
  2. Enter a name for the job: hello-world
  3. Select Pipeline, then click OK.
Choose names without spaces, for example hello-world, not "Jenkins pipeline example-Hello World" as in the screenshot. Jenkins creates a folder with this name, and spaces cause problems in shell commands later.

Step 2: Write the pipeline

The configuration page opens. Scroll down to the Pipeline section (or click Pipeline in the left menu). Check that Definition is set to Pipeline script, then paste this code into the Script box:

Your first declarative pipeline
pipeline {
    agent any
    stages {
        stage('Hello') {
            steps {
                echo 'Hello World'
            }
        }
    }
}
Simple button to try: above the Script box, the drop-down try sample Pipeline… offers ready-made examples. Choose Hello World to see a similar script written for you.

Step 3: Save and run

  1. Click Save. You arrive on the job page.
  2. Click Build Now in the left menu.
  3. A new line #1 appears in Build History (bottom left). A green tick means the build succeeded.

Step 4: Read the logs

Click #1, then Console Output. You see everything Jenkins did:

The pipeline ran and printed Hello World. The last line, Finished: SUCCESS, is the final result of the build.

Step 5: See the stages

Go back to the job page (click hello-world in the breadcrumbs at the top). Jenkins shows the stages of each build, with their duration: here, a single stage called Hello.

Your screen may look different. Since 2024, new Jenkins installations show the stages as a graph (Pipeline Graph View plugin) instead of this "Stage View" table: open build #1 to see it. To get the table shown here, install the Pipeline: Stage View plugin (Manage Jenkins › Plugins › Available plugins).
