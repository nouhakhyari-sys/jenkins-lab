Lab 2 · Your First Pipeline

7. Bonus: Run a Pipeline from Git

Finished early? Until now, you typed the script in the Jenkins Script box. In real projects, the script is a file named Jenkinsfile, stored in Git with the code. Jenkins reads it from the repository at every build. This is called Pipeline as Code.

Part 1: Run a Jenkinsfile from GitHub (10 min)

Your teacher's public repository contains this file, in the folder examples/hello-from-git:

examples/hello-from-git/Jenkinsfile (already on GitHub, nothing to copy)
pipeline {
    agent any
    stages {
        stage('Hello from Git') {
            steps {
                echo 'Hello World! This script was read from GitHub.'
            }
        }
    }
}

Step 1: Create the job. On the dashboard, click New Item, type hello-from-git, select Pipeline, then click OK.

Step 2: Read the script from Git. Scroll to the Pipeline section and fill in the fields in this order:

  1. Definition: choose Pipeline script from SCM (SCM = Source Code Management).
  2. SCM: choose Git. New fields appear below. Only None in the list? See "SCM shows only None" below.
  3. Repository URL: paste the address below.
Repository URL
https://github.com/nouhakhyari-sys/jenkins-labs-template.git
  1. Credentials: leave - none -. The repository is public.
  2. Branch Specifier: replace */master with */main. GitHub names the main branch main.
  3. Script Path: replace Jenkinsfile with the path of the file inside the repository:
Script Path
examples/hello-from-git/Jenkinsfile
Do not mix up the two fields. The GitHub address goes in Repository URL. Script Path only contains the folder and the file name inside the repository.
  1. Leave Lightweight checkout ticked. Click Save.

Step 3: Run it. Click Build Now, then #1 › Console Output. You see:

Console Output (extract)
Obtained examples/hello-from-git/Jenkinsfile from git
  https://github.com/nouhakhyari-sys/...
...
[Pipeline] echo
Hello World! This script was read from GitHub.
...
Finished: SUCCESS

Jenkins downloaded the Jenkinsfile from GitHub, then ran it. The script is no longer stored in Jenkins: it lives in Git.

Part 2: Run your own Jenkinsfile (15 min)

Now Jenkins reads your lab2/Jenkinsfile, the one you handed in. Your repository is private, so Jenkins needs a key to read it: a GitHub token.

Step 1: Create a token on GitHub.

  1. On GitHub, click your photo (top right) › Settings › Developer settings (bottom of the left menu) › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Token name: jenkins-lab. Expiration: 30 days.
  3. Repository access: Only select repositories › choose jenkins-labs.
  4. Permissions › Repository permissions › Contents: Read-only.
  5. Click Generate token and copy it now: GitHub shows it only once. It starts with github_pat_.

Name ≠ value. jenkins-lab is only the name of the token, a label. The value is the long secret text (github_pat_11A…, about 90 characters) shown once, just after Generate token. Jenkins needs the value. Lost it? Open the token on GitHub and click Regenerate token.

A token is a password. Never paste it in a script, a screenshot or a file of your repository. Only in Jenkins Credentials.

Step 2: Create the job. New Item › my-pipeline-from-git › Pipeline › OK. In the Pipeline section:

  1. Definition: Pipeline script from SCM. SCM: Git.
  2. Repository URL: the address of your repository, ending with .git, for example https://github.com/your-username/jenkins-labs.git
  3. Credentials: click + Add › Jenkins. Kind: Username with password. Username: your GitHub username. Password: paste the token. ID: github-token. Click Add, then select the new credential in the list.
  4. Branch Specifier: */main. Script Path: lab2/Jenkinsfile. Click Save.

Step 3: Run it, with Build Now. Your Build, Test and Deploy stages run, read from GitHub.

Step 4: Change the code, not Jenkins. On GitHub, open lab2/Jenkinsfile, click the pencil icon, change an echo message, then Commit changes. In Jenkins, click Build Now again: the new message appears. You changed the pipeline without opening Configure. This is how real teams work.

Troubleshooting

SCM shows only None

The Git plugin is missing. Install it like the Stage View plugin (page 0): Manage Jenkins › Plugins › Available plugins, search Git, tick Git ("This plugin integrates Git with Jenkins"), click Install, wait for Success. Then open your job, click Configure: Git is in the SCM list.

Error "Couldn't find any revision to build"

The branch is wrong. In Configure, set Branch Specifier to */main, not */master.

Error "java.io.IOException: Directory"

The Script Path points to a folder, not to a file. Add the file name at the end: examples/hello-from-git/Jenkinsfile (not examples/hello-from-git), or lab2/Jenkinsfile (not lab2).

Error "Unable to find examples/… from git" or "…/Jenkinsfile not found"

The Script Path is wrong. It is case-sensitive and has no address in it: examples/hello-from-git/Jenkinsfile (Part 1) or lab2/Jenkinsfile (Part 2). Check that the file exists at that place on GitHub.

Error "Authentication failed" or "repository not found" (Part 2)

Jenkins cannot read your private repository. Check, in this order:

  1. A credential is selected in the Credentials list of the job, not "- none -".
  2. Its Kind is Username with password, not "Secret text" (a Secret text does not appear in the Git list).
  3. Username = your GitHub username, Password = the token value (github_pat_… or ghp_…), not the token name and not your GitHub password.
  4. The fine-grained token gives Contents: Read-only access to jenkins-labs, and its Resource owner is your account.

Still failing? Use a classic token, simpler: GitHub › Settings › Developer settings › Personal access tokens › Tokens (classic) › Generate new token (classic) › tick repo › Generate token. Copy it (it starts with ghp_), then in Jenkins edit the credential (Manage Jenkins › Credentials) and paste it as Password.

Error "Cannot run program "git"" (Jenkins installed on Windows)

Git is not installed on the computer that runs Jenkins. The Docker Jenkins already contains Git. On a Jenkins installed on Windows, install Git for Windows from git-scm.com, then restart Jenkins.
