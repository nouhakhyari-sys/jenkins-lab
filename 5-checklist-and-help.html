Checklist

Before leaving the lab, check that:

  • ☐ The jenkins-local container is running (docker ps).
  • ☐ Jenkins opens at http://localhost:8080.
  • ☐ The suggested plugins are installed.
  • ☐ You created your own administrator account and can log in with it.
  • ☐ You found your Jenkins version in the footer.

Troubleshooting

"Port 8080 is already in use"

Another program uses port 8080. Start the container on another host port, then open http://localhost:8081:

docker run -d --name jenkins-local -p 8081:8080 -p 50000:50000 -v jenkinsvol:/var/jenkins_home jenkins/jenkins:lts-jdk21

"This site can't be reached" at localhost:8080

Check that the container is running with docker ps. If you used Docker Desktop, check that the host port for 8080/tcp is filled in. Jenkins also needs about a minute to start: wait and refresh.

"Cannot connect to the Docker daemon" or "docker: command not found"

Docker is not installed or not started. Start Docker Desktop (or the Docker service on Linux), wait until it is ready, then try again.

"The container name is already in use"

A container called jenkins-local already exists. Start it with docker start jenkins-local, or remove it with docker rm -f jenkins-local and run the command again. Your data stays in the jenkinsvol volume.

No initialAdminPassword file

Check the container name in your command. If you have already completed the setup wizard, the file is deleted: log in with the administrator account you created.

Some plugins failed to install

Usually a network problem. Click Retry. If your school network uses a proxy, ask your teacher.

I forgot my admin password

In this lab, the simplest way is to start again from zero (this deletes all your Jenkins data):

docker rm -f jenkins-local
docker volume rm jenkinsvol

Then run the docker run command from page 2.4 again.
