2.5 Kubernetes (Helm)

To run Jenkins in Kubernetes, use the official Helm chart. Helm is the package manager for Kubernetes: it finds, shares and installs software built for Kubernetes. Install Helm first. Full guide: Installing Jenkins on Kubernetes.

In the commands below, replace yourname with your own Kubernetes namespace.

1. Add the Jenkins chart repository and look at the available charts:

Add the Jenkins Helm repository
helm repo add jenkinsci https://charts.jenkins.io
helm repo update
helm search repo jenkinsci

2. Install Jenkins in your namespace (the chart name is lowercase):

Install the Jenkins chart (skip the first line if the namespace already exists)
kubectl create namespace yourname
helm install jenkins jenkinsci/jenkins -n yourname

3. Check the pods and services. Wait until the pod jenkins-0 has the status Running; it can take a few minutes.

Check that Jenkins is running
kubectl get pods -n yourname
kubectl get services -n yourname

4. Get the admin password:

Display the admin password
kubectl get secret jenkins -n yourname \
  -o jsonpath="{.data.jenkins-admin-password}" | base64 --decode; echo

5. Forward a local port to the Jenkins pod, so you can open it from your browser:

Make Jenkins reachable on localhost:8080
kubectl port-forward jenkins-0 8080:8080 -n yourname

6. Open http://localhost:8080 and log in with the user admin and the password from step 4. The Helm chart prepares Jenkins for you, so you may not see the setup wizard.
