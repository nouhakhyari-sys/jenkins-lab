Lab 4 · Freestyle Projects and Blue Ocean

7. The Successor: Pipeline Graph View

Pipeline Graph View is the plugin the Jenkins project now recommends instead of Blue Ocean. It shows the graph of a run inside the classic interface, with the logs of each stage, and it is actively maintained.

Step 1: Check that it is installed

  1. Manage Jenkins › Plugins › Installed plugins, search Pipeline Graph View.
  2. Not there? Install it from Available plugins, like Blue Ocean.

Step 2: Open a run

  1. In the classic interface, open my-java-pipeline and click a build number (for example #7), not the job itself.
  2. In the left menu of the build, click Pipeline Overview.
  3. Click a stage in the graph: its log appears next to it.

Blue Ocean vs Pipeline Graph View

Blue OceanPipeline Graph View
StatusDeprecated since July 2026, no more fixesActively maintained
InterfaceA separate interfaceInside the classic Jenkins pages
Graph and logs per stageYesYes
Graphical editorYesNo: use the Snippet Generator (Pipeline Syntax)
Question: you install Jenkins for a company today. Which one do you choose to visualise pipelines?

Pipeline Graph View (with Stage View): it is maintained and receives security fixes. Installing a plugin that no longer gets security fixes on a production server is a risk. Blue Ocean taught you how a pipeline is built; the Snippet Generator now does the editor's job.
