Lab 3 · Build a Java Project

3. Run It from GitHub

Jenkins reads the Jenkinsfile from the teacher's public repository. Public means: no token, no credentials.

Step 1: Create the job

On the dashboard, click New Item, type java-calculator, select Pipeline, then OK.

Step 2: Fill in the Pipeline section, in this order

  1. Definition: Pipeline script from SCM.
  2. SCM: Git.
  3. Repository URL: copy this address. Nothing after .git.
Repository URL
https://github.com/nouhakhyari-sys/jenkins-labs-template.git
  1. Credentials: - none -. Do not add anything.
  2. Branch Specifier: replace */master with */main.
  3. Script Path: the path of the file, depending on your Jenkins:
Script Path: Jenkins in Docker
lab2/java-app/Jenkinsfile
Script Path: Jenkins installed on Windows
lab2/java-app/Jenkinsfile-windows
  1. Click Save.
The 3 classic mistakes
❌ …/tree/main or …/blob/… in Repository URL: that is a web page, not the repository.
❌ */master: GitHub calls the branch main.
❌ lab2/java-app in Script Path: that is a folder (error "Directory"). Give the file: …/Jenkinsfile.

Step 3: Run it

  1. Click Build Now.
  2. When the build is finished (green tick), click #1, then Console Output.

In the log, find:

  • Obtained lab2/java-app/Jenkinsfile from git …: Jenkins read the script on GitHub;
  • PASS add_2_and_3 … 4 tests, 0 failure(s): the tests ran;
  • Archiving artifacts and Deleting project workspace: two plugins at work;
  • Finished: SUCCESS.
After the first build, the Build Now button becomes Build with Parameters: the Jenkinsfile declares a parameter (SIMULATE_BUG) and Jenkins discovered it during the first build. You will use it in part 5.
