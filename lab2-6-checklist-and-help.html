6. Checklist and Help

Checklist

Before leaving the lab, check that you have:

  • ☐ The Pipeline: Stage View plugin installed.
  • ☐ A green hello-world job that prints Hello World.
  • ☐ A shell-commands job showing hostname and uptime.
  • ☐ A my-first-pipeline job with three stages: Build, Test, Deploy.
  • ☐ One red build (exercise 2), followed by a green one.
  • ☐ Tried Replay and the Snippet Generator (Pipeline Syntax).

Hand in your work

In your lab repository on GitHub, add:

  • a file named Jenkinsfile containing your final my-first-pipeline script;
  • screenshots/lab2-stages.png: the stages of my-first-pipeline, with the red and the green builds;
  • screenshots/lab2-console.png: the Console Output of the failed build, showing the error.

Troubleshooting

Error "WorkflowScript: … expecting '}'" or "unexpected token"

A syntax error. The message gives the line number. Check that every { has its }, and that every text is between quotes. In the Script box, a red cross in the margin shows the line with the problem.

Error "Cannot run program "sh" … CreateProcess error=2"

Your Jenkins runs directly on Windows (the path in the message looks like C:\Users\…\.jenkins\workspace), not in Docker. Windows has no sh.

Best fix: use the Docker Jenkins of Lab 1 (http://localhost:8080 served by the jenkins-local container), where sh works.

Quick fix: replace sh with bat and use Windows commands:

echo "Hello World!"
bat "echo Hello from the Windows shell"
bat "hostname"
bat "ver"

uptime does not exist on Windows; ver prints the Windows version instead.

Error "No such DSL method …"

A step name is misspelled, for example ech instead of echo. Correct the name; Pipeline Syntax shows the exact name of every step.

The build stays grey: "Waiting for next available executor"

Jenkins has no free executor to run the build. Go to Manage Jenkins › Nodes › Built-In Node › Configure and check that Number of executors is at least 1 (2 by default).

The message shows ${env.BUILD_NUMBER} instead of a number

The text is between single quotes. Use double quotes: echo "Build number: ${env.BUILD_NUMBER}".

I cannot see the Stage View table

Install the Pipeline: Stage View plugin (page 0), run at least one build, then refresh the job page. You can also click Stages in the left menu to see the stages as a graph.

Jenkins does not open any more at localhost:8080

The container stopped, for example after restarting your computer. Run docker start jenkins-local, wait a minute, and refresh.
