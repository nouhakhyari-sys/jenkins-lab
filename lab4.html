Lab 4 · Freestyle Projects and Blue Ocean

Lab 4 – Freestyle Projects and Blue Ocean

Until now you wrote every job as a pipeline (a Jenkinsfile). In this lab you meet the older way to create jobs in Jenkins, the Freestyle project, and see why pipelines replaced it. Then you discover Blue Ocean, a graphical interface for pipelines, and its successor, Pipeline Graph View.

Objectives

  • Create a Freestyle job with forms only: Git repository, parameter, build step, test report and artifact.
  • Chain two Freestyle jobs and compare Freestyle with Pipeline.
  • Install Blue Ocean and read a pipeline run in it: stages, logs, tests, artifacts, approval.
  • Create a pipeline with the Blue Ocean editor, with two parallel stages, saved as a Jenkinsfile in your GitHub repository.
  • See a multibranch pipeline build a new branch and a pull request by itself, before the merge.
  • Open the same run in Pipeline Graph View, the maintained successor of Blue Ocean.

Session plan (1h30)

  1. Your first Freestyle job (20 min)
  2. Freestyle vs Pipeline (15 min)
  3. Install Blue Ocean (10 min)
  4. Explore a run in Blue Ocean (10 min)
  5. The Blue Ocean editor (20 min)
  6. Branches and pull requests (10 min)
  7. The successor: Pipeline Graph View (5 min)
  8. Checklist and hand-in (5 min)

Before you start

  • Jenkins is running and you can log in at http://localhost:8080.
  • Lab 3 is done: you have the job my-java-pipeline (part 6), with the Deploy stage.
  • You have your own jenkins-labs repository on GitHub (the one you use to hand in your work).
Jenkins in Docker or on Windows? As in Lab 3, every command exists in two versions. Jenkins in Docker uses shell commands (sh, Execute shell, Shell Script). Jenkins installed directly on Windows uses batch commands (bat, Execute Windows batch command, Windows Batch Script). Always take the version that matches your Jenkins.
