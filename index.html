CI/CD with Jenkins – Labs

Welcome to the lab guides of the CI/CD with Jenkins module. Each lab is a step-by-step guide: follow the pages in order, copy the commands with the Copy buttons, and check your work with the checklist at the end.

📥 Hand in your work

You hand in your lab work in a personal GitHub repository, with one folder per lab. Set it up once, at the start of the module, with the guide How to hand in your work. At the end of each lab, the last page tells you which files to add, and in which folder.
