Lab 1 · Installing Jenkins

2.2 Linux Packages

Linux package managers (APT on Debian/Ubuntu, DNF/YUM on Red Hat/Fedora…) provide a stable, automated way to install and manage software. The package still uses jenkins.war, but adds useful extras: a dedicated jenkins user, a system service that starts automatically, and log management.

Example: Jenkins LTS on Ubuntu / Debian

1. Install Java 21 first (Jenkins cannot start without it):

Install Java 21
sudo apt update
sudo apt install fontconfig openjdk-21-jre
java -version

2. Add the Jenkins repository and install Jenkins:

Add the Jenkins LTS repository and install
sudo wget -O /etc/apt/keyrings/jenkins-keyring.asc \
  https://pkg.jenkins.io/debian-stable/jenkins.io-2026.key
echo "deb [signed-by=/etc/apt/keyrings/jenkins-keyring.asc]" \
  https://pkg.jenkins.io/debian-stable binary/ | sudo tee \
  /etc/apt/sources.list.d/jenkins.list > /dev/null
sudo apt update
sudo apt install jenkins
Always copy these commands from the official page. The repository key changes over time (the 2023 key was replaced by a 2026 key), and old tutorials using apt-key no longer work. Official instructions: Installing Jenkins on Linux.

Manage the Jenkins service

Start, check and stop Jenkins
sudo systemctl start jenkins
sudo systemctl status jenkins
sudo systemctl stop jenkins

Change the port

On current versions, Jenkins settings are changed with a systemd override (the old /etc/default/jenkins file is no longer used). Run the command below, add the two lines shown, save, then restart Jenkins:

Use port 8083 instead of 8080
sudo systemctl edit jenkins

# add these two lines in the editor:
[Service]
Environment="JENKINS_PORT=8083"

sudo systemctl restart jenkins

Where things are

  • Jenkins home directory: /var/lib/jenkins
  • Initial admin password: sudo cat /var/lib/jenkins/secrets/initialAdminPassword
  • Logs: journalctl -u jenkins
