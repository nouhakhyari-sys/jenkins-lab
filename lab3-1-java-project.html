Lab 3 · Build a Java Project

1. Meet the Java Project

Open the project on GitHub: lab2/java-app. It is a tiny calculator, with no Maven and no library: Jenkins only needs the Java compiler it already has.

The files of the project
lab2/java-app/
├── src/Calculator.java        the application: add() and multiply()
├── test/CalculatorTest.java   4 tests
├── Jenkinsfile                the pipeline for Jenkins in Docker (sh)
└── Jenkinsfile-windows        the same pipeline for Jenkins on Windows (bat)

Read the code

  1. Click src/Calculator.java. Find the two methods add and multiply. Notice the line with simulateBug: it adds 1 to every addition when the bug is switched on. You will use it in part 5.
  2. Click test/CalculatorTest.java. It checks 4 results, for example check("add_2_and_3", 5, calc.add(2, 3)), and writes a report in the JUnit XML format, the standard format Jenkins understands.
  3. Click Jenkinsfile. Find the three stages Build, Test and Package.

What each stage does

  • Build: javac compiles the two .java files into .class files.
  • Test: java … CalculatorTest runs the tests. Then junit (the JUnit plugin) reads the report and shows it in Jenkins.
  • Package: jar puts the compiled code in calculator.jar, then archiveArtifacts keeps this file so you can download it.
  • options: timestamps() (Timestamper plugin) writes the time on each log line. post › always: cleanWs() (Workspace Cleanup plugin) deletes the files at the end.
dir('lab2/java-app') runs the commands inside that folder of the repository, like cd lab2/java-app in a terminal.
