Lab 3 · Build a Java Project

8. Checklist and Help

Checklist

  • ☐ java-calculator runs from GitHub, green.
  • ☐ I found the 4 plugins at work: Timestamper, JUnit, Artifacts, Workspace Cleanup.
  • ☐ One yellow (UNSTABLE) build with SIMULATE_BUG, then a green one.
  • ☐ my-java-pipeline with Checkout, Build, Test, Package and Deploy.
  • ☐ One build approved (Deploy) and one aborted (Abort).
  • ☐ AnsiColor installed, coloured messages in the log.

Hand in your work

In your jenkins-labs repository, open the lab3 folder and add (guide: How to hand in your work):

  • lab3/Jenkinsfile: your final my-java-pipeline script (copy it from Configure);
  • lab3/test-result.png: the Tests page of the yellow build;
  • lab3/stages.png: the Stage View of my-java-pipeline with the Deploy column.

In the commit message of your Jenkinsfile, answer the question of part 5: would you deploy the jar of a yellow build?

Troubleshooting

Error "Repository not found" or "Failed to connect to repository"

Check Repository URL: exactly https://github.com/nouhakhyari-sys/jenkins-labs-template.git, with nothing after .git. Credentials: - none -. The repository is public: no token is needed.

Error "Couldn't find any revision to build"

Branch Specifier is still */master. Change it to */main.

Error "java.io.IOException: Directory"

Script Path is a folder. Give the file: lab2/java-app/Jenkinsfile (Docker) or lab2/java-app/Jenkinsfile-windows (Windows).

Error "Cannot run program "sh"" (Windows)

You used the Docker version on a Jenkins installed on Windows. Use Jenkinsfile-windows in Script Path, or bat instead of sh in your script.

"javac: not found" (Docker) or "'javac' is not recognized" (Windows)

Docker: the official image jenkins/jenkins:lts-jdk21 contains javac; check that you use this image (docker ps, column IMAGE).

Windows: Jenkins runs with a Java runtime only. Install a JDK 21 (for example Eclipse Temurin, with the option "Add to PATH"), then restart Jenkins. Check in a Command Prompt: javac -version.

Error "No such DSL method 'junit'", 'cleanWs' or "Invalid option type timestamps"

A plugin is missing: JUnit, Workspace Cleanup or Timestamper. Install it from Manage Jenkins › Plugins › Available plugins, then build again.

The build waits for ever on Deploy

That is the input step: it waits for you. Open Console Output and click Deploy or Abort, or hover the Deploy cell in Stage View.

No "Build with Parameters" button

Run the job once with Build Now: Jenkins reads the parameters block during the first build. The button appears after it.
